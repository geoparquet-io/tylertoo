# tylertoo-io

Checked Parquet and Arrow IPC I/O for [`tylertoo-core`](https://crates.io/crates/tylertoo-core).

This crate is an implementation detail of `tylertoo-core`. It is published
only because `tylertoo-core` depends on it, and it has no stability
guarantee: any release may change or remove any item. Depend on
`tylertoo-core` (library) or `tylertoo` (CLI) instead.
