Export an overview file to a PMTiles archive, one zoom per level.

Args:
    input: Overview file from `overview()`.
    output: PMTiles archive to write.
    layer_name: MVT layer name.
    tile_buffer: Tile edge buffer in pixels, at most 256.
    preset: `"tippecanoe"` starts from tippecanoe's tile buffer, size
        limits and size valve instead of tylertoo's; an option you pass
        still applies. See
        [the tippecanoe preset](https://geoparquet-io.github.io/tylertoo/guides/tippecanoe/#the-tippecanoe-preset).
    extent: Tile resolution in MVT units.
    tile_size_limit: Maximum raw (uncompressed) tile size in
        bytes, a backstop behind `max_compressed_tile_size`;
        `"auto"` is 2 MiB, and `0` or `None` is no limit.
    simple_clip_fastpath: Use faster clipping for simple polygons.
        `False` gives byte-stable output.
    partition_wave: [Partitions in memory](https://geoparquet-io.github.io/tylertoo/guides/scaling/#export-waves)
        at once, or `0` to size from CPUs and RAM.
    feature_order: Paint order within a tile: `"input"`, or a
        property name with an optional `:asc` or `:desc`.
    min_zoom: Coarsest zoom to declare when the coarsest levels are
        empty.
    include_properties: Keep only these properties in the tiles.
        The overview file keeps every column, and the
        `feature_order` column must stay. `[]` keeps none.
    exclude_properties: Drop these properties from the tiles.
        `include_properties` overrides it.
    exclude_all_properties: Drop every property, writing
        geometry-only tiles. `include_properties` overrides it.
    feature_id: Integer column to use as the MVT feature ID. By default,
        features have no ID.
    spill_dir: [Spill directory](https://geoparquet-io.github.io/tylertoo/guides/scaling/#spill-files)
        used when memory runs short.
    profile: [Memory profile](https://geoparquet-io.github.io/tylertoo/guides/scaling/#memory-profiles):
        `"speed"` holds everything in RAM, `"bounded"` uses disk and
        holds the least, and `"auto"` sizes to the machine's memory.
        Footprints compare for one allocator: wheels use mimalloc, which
        adds a fixed floor of about 600 MiB on small inputs. On a 1.4M
        polygon export it ran 8% faster and held 18% more peak memory
        than the system allocator; a non-musl source build can opt out
        with `maturin build --no-default-features` (musl always uses
        mimalloc). Output is
        identical across profiles.
    name: Human-readable tileset name, stored in the metadata.
    description: Description of the tileset, stored in the metadata.
    attribution: Attribution text or HTML stored in the archive
        metadata; MapLibre shows it in its attribution control.
        Each value is stored as given, and `""` is kept as `""`.
    size_valve: How to reduce a tile that exceeds its limit:
        `"merge"` merges the densest lines and polygons into a
        neighbor, which keeps its own attributes; `"drop"` removes
        features, leaving holes. Point tiles use feature dropping in
        both modes.
    max_compressed_tile_size: Maximum gzip-compressed tile size
        in bytes, like tippecanoe's `-M`; `"auto"` is 500 KiB, and
        `0` or `None` is no limit.
    max_zoom_simplify_factor: Simplify each feature of the finest
        (canonical) level once, before clipping, with tolerance factor ×
        GSD at that level's zoom, like `simplify_factor` for coarser
        levels. With the default GSD base, 1 GSD is 4 tile units at
        extent 4096. Features smaller than the tolerance keep their own
        geometry. Defaults to None (off). Changes the output; leaves
        coarser levels unchanged, except that variable-depth stop tiles
        carry the simplified finest-level features. Leaves the overview
        file unchanged. Comparable to
        tippecanoe's `-S`, which uses tile units at every zoom:
        `-S 10` is about factor 2.5.
    coverage_fill: Experimental: under each tile's features, draw
        the area its child tiles cover, so a polygon coverage shows
        no holes at coarse zooms. Holds the finest level's geometry
        in memory. See `docs/OVERVIEW_TUNING.md`.
    variable_depth: End each branch of the tile pyramid at the
        coarsest zoom whose tile holds all of that area's finest-level
        features within both size caps, like tippecanoe's
        `--generate-variable-depth-tile-pyramid`. The server must serve
        the nearest ancestor for a missing tile. See
        `docs/OVERVIEW_TUNING.md`.
    tile_range: Export only the tiles in this tile-id range,
        `"LO..HI"`: one shard of a sharded build.
    zoom_ceiling: Export only the tiles at or below this zoom: the
        coarse job of a sharded build.
    tile_format: Tile encoding, `"mvt"` (default) or `"mlt"`. MLT needs
        MapLibre GL JS 5.12 or later, or MapLibre Native. Each finished
        MVT tile is converted with mlt-core before gzip and both size
        caps, so the caps measure MLT bytes. MLT stores each attribute
        of a layer as one typed column, following mlt-core's MVT
        conversion: integers mixed with floats become f64 (doubles),
        and other mixes become strings. Attribute order within a
        feature becomes column order. MLT archives use PMTiles tile
        type 6 and metadata format `"mlt"`. Merge refuses to combine
        MVT and MLT archives.
    mlt_profile: MLT profile, refused unless `tile_format="mlt"`.
        `"web"` (default) targets GL JS before 6.0, which decodes with
        @maplibre/mlt 1.1. It omits FastPFOR, FSST and shared
        dictionaries, and stores integer columns wider than 32 bits
        as doubles when every value is exact (absolute value at most
        2^53): GL JS reads 64-bit integers as BigInt, and style
        expressions do not compare BigInt with numbers. The others
        are mlt-core's profiles: `"native"` for MapLibre Native with
        every codec and stored polygon triangles; `"min-size"` for
        smallest tiles; `"diffable"` for small binary diffs between
        releases; `"fast-encoding"` for quickest encoding.

Returns:
    Tile counts for each zoom written, with encoding diagnostics.

Raises:
    ConfigError: An option out of range or refused, such as
        `tile_buffer` past 256, `extent=0`, a missing `spill_dir`,
        or metadata too large for the 16 MiB archive metadata.
    ValueError: A property selection the overview file cannot
        satisfy.
    RuntimeError: Not an overview file, or reading or writing
        failed.

Example:
    >>> report = export_pmtiles("overview.parquet", "out.pmtiles")
    >>> report["max_zoom"]
    10
    >>> credited = export_pmtiles(
    ...     "overview.parquet",
    ...     "credited.pmtiles",
    ...     attribution="© Example contributors",
    ... )
    >>> credited["zooms"] == report["zooms"]
    True
